# Penumbra still renders (visual assets, not science data)

Own renders of the real NASA PGDA 78 Site04 5 m LOLA DEM (`Site04_final_adj_5mpp_surf.tif`,
https://pgda.gsfc.nasa.gov/data/LOLA_5mpp/Site04/), made for the Penumbra V3 design (14 Nov 2026):
ray-marched cast shadows, Lommel-Seeliger-like shading, ACES tone map. No terrain added or removed.

**Illustrative lighting:** the Sun direction (grid azimuth 120°, elevation 1.5°) and the cameras were chosen
for composition. They are NOT a solver time step and must be captioned as illustrative wherever shown.

| File | Camera | Use |
|---|---|---|
| hero.webp | oblique, Sun in frame | Landing hero |
| wall.webp | low, toward a lit slope | Landing chapter 03 |
| app.webp | approach, 900 m above ground | Story / fallback still |
| map.webp | overhead | Landing receipts |
