NASA describes the models as derived from Lunar Reconnaissance Orbiter imagery
and topographic data and intended for web interactives, AR and animation. The
primary 81,505,784-byte GLB contains 2,021,340 vertices and 1,015,808 triangles;
NASA categorizes it as an 8K color-map and height-map model. It is used only for
global orientation/navigation and is not sampled by POLARIS X calculations. The
local PGDA DEM remains the terrain authority. The compact 13.2 MB color-only GLB
is retained as a provenance/fallback asset but is not loaded by the main viewer.
